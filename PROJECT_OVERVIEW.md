# Біблійна гра: Огляд Проекту (Project Overview)

Цей документ створений для того, щоб одразу було зрозуміло суть, концепцію та архітектуру проекту "Біблійна гра", а також напрямок його розвитку.

## 1. Суть Проекту
**Біблійна гра** — це Telegram Mini App (вікторина) для глибокого вивчення та перевірки знань Біблії. Мета застосунку не просто розважати, а заохочувати гравців досліджувати Святе Письмо через інтерактивні режими, систему досягнень та прогресу.

## 2. Основні Режими Гри
Застосунок пропонує кілька унікальних ігрових режимів, кожен з яких має свою мету:

1. **Дослідження (колишнє "Соло")**: 
   - *Мета*: Глибоке вивчення Біблії.
   - *Особливість*: Гравець вибирає конкретні теми і занурюється в підтеми (наприклад: Географія -> Міста -> Єрусалим). Це основний навчальний режим.
2. **Міліонер**:
   - *Мета*: Розважальний формат вікторини з підказками (50/50, допомога залу).
   - *Особливість*: Використовує загальну базу тем, питання йдуть від легких до складних.
3. **Виживання (Survival)**:
   - *Мета*: Перевірка витривалості. Гра йде до першої (або кількох) помилок.
4. **Kahoot (Мультиплеєр)**:
   - *Мета*: Командна або змагальна гра в реальному часі через кімнати (з використанням WebSocket/сервера).

## 3. Навігація та Інтерфейс (UX/UI)
Застосунок побудований з акцентом на сучасний, зручний інтерфейс:
- **Головна (Дашборд)**: Віджет "Вірш дня", щоденні завдання, швидка кнопка "Продовжити гру" та короткий огляд прогресу.
- **Гра/Режими (Play Hub)**: Гарно оформлене меню вибору ігрових режимів (картки режимів).
- **Крамниця (Shop)**: Внутрішньоігровий магазин, де за зароблені монети гравці можуть купувати косметичні предмети (наприклад, Аватари).
- **Профіль**: Особистий кабінет гравця. Тут знаходиться вибраний Аватар, загальний рейтинг, кабінет досягнень та детальна статистика "Прогрес за темами".

## 4. Архітектура Даних (Теми та Питання)
Для того, щоб забезпечити як розважальний, так і глибокий навчальний процес, база даних розділена:

- **База для базових ігор (`themes.ts`)**: Використовується в режимах "Міліонер", "Виживання" тощо. Містить загальні широкі теми без складних розгалужень.
- **База "Дослідження" (`study_themes.ts`)**: Має деревоподібну структуру (Теми -> Підтеми -> Питання). Дозволяє гравцю цілеспрямовано вивчати конкретні аспекти Біблії.

Питання можуть бути написані вручну або згенеровані за допомогою локального ШІ (Ollama) через скрипти автоматизації (`npm run generate-ai`).

## 5. Економіка та Прогрес
- **Очки складності**: Гравці отримують різну кількість очок залежно від обраної складності рівня (Початковий, Легкий, Середній, Складний, Експерт).
- **Монети/Валюта**: Заробіток для витрат у Крамниці.
- **Досягнення**: Спеціальні бейджі або нагороди за проходження певних тем, серію правильних відповідей тощо.

## 6. Технічний Стек
- **Frontend**: React 19 + TypeScript, збірка через Vite.
- **Стилізація**: Vanilla CSS (CSS Modules: `*.module.css`) з використанням сучасних ефектів (градієнти, мікро-анімації).
- **Платформа**: Telegram Mini App (використовується `@twa-dev/sdk` для отримання імені гравця, інтеграції з UI Telegram).
- **Локальне збереження**: На даному етапі використовується `localStorage` браузера/Telegram, з можливістю підключення хмарної бази даних у майбутньому (Supabase/Firebase).

## 7. Як це працює зсередини (Для розробників)
- Всі екрани знаходяться в папці `src/pages/`.
- Загальні компоненти (Нижнє меню, Картки) — в `src/components/`.
- Дані та логіка питань — в `src/data/`.
- Глобальний стан (Очки, Аватари) керується через Context API (`src/context/PlayerContext.tsx`).
- Всі шляхи (URL) налаштовані в `App.tsx` через `React Router`.

Цей документ слугує орієнтиром ("компасом") для всіх майбутніх оновлень та масштабування проекту.
