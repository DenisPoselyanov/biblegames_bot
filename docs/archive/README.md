# Bible Games — архів документації

Ця папка містить старі, замінені або історичні документи.

## Важливо

- Архів не є джерелом актуальних вимог.
- Статуси `Completed`, старі номери фаз і старі пріоритети не переносяться в поточний roadmap автоматично.
- AI-агенти не повинні планувати нову роботу за файлами з цієї папки.
- Архівний документ можна використовувати лише для відновлення історичного контексту або перевірки походження рішення.

## Вміст

- `CURRENT_STATE_AUDIT.md` — baseline-аудит стану репозиторію на момент перебудови документації.
- `DESIGN_AUDIT.md` — історичний знімок UI/design-system debt.
- `MASTER_ROADMAP.md` — попередній master roadmap.
- `AI_SYSTEM_REBUILD_ROADMAP.md` — попередній окремий AI roadmap.
- `implementation_plan.md` — старий план Study 2.0.
- `task.md` — старий task board Study 2.0.
- `CODEX_MASTER_EXECUTION_PROMPT.md` — архівна compatibility-сторінка для старої Codex-specific назви execution prompt.

Актуальна документація знаходиться на рівень вище: [docs/README.md](../README.md).
