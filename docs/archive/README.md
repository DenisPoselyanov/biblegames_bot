# Archive

Ця папка містить історичні документи, замінені канонічною структурою в `docs/`.

- `legacy-product-rebuild/` — остання повна версія старого Phase 0–13 roadmap, audit, decisions та AI roadmap на момент міграції.
- `legacy-root/` — колишні root-level design, guide, tools і task documents.
- `legacy-scripts/` — замінені інструкції інструментів.

Архів зберігається для історії, commit evidence та аналізу відхилень. Він **не визначає** поточний scope, status, phase order або implementation instructions.

Поточні документи: [`../README.md`](../README.md). Карта міграції: [`../ROADMAP_MIGRATION.md`](../ROADMAP_MIGRATION.md).
