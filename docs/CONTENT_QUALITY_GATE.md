# Ворота якості контенту (WS11)

Навіщо: ручна перевірка банку питань знайшла питання не в своїй темі й вигадки, яких детерміновані перевірки WS3 не бачать, а publish gate WS6 пропускав «ніколи не перевірене» як «чисте». Ворота мають п'ять шарів, і жоден із них сам нічого не публікує.

| Шар | Що робить | Де |
|---|---|---|
| L0 — структура | WS3-перевірки, росіянізми, зсув позиції правильної відповіді | `server/domains/content/qualityChecks.ts` |
| L1 — посилання | немає/нерозпізнане посилання (блокер), «1 Цар.» (неоднозначне), книга поза темою | там само + `themeCanon.ts` |
| L2 — AI-рецензент | 8 критеріїв + вердикт, на основі тексту віршів (Огієнко, bolls.life) | `server/domains/quality/aiReview*.ts`, `npm run ai -- ai-review` |
| L3 — людське рішення | черга Studio за ризиком: прийняти / змінити / залишити | Studio → Черга → AI-рецензія |
| L4 — сигнали гравців | скарги й аномальна точність піднімають питання в черзі | `server/domains/quality/playerSignals.ts` |

Вердикти: **Відхилити** → питання прибирається з гри (`data/question-exclusions.json`, ревізії — в карантин, нічого не видаляється фізично) · **Виправити** → нові пояснення або AI-виправлення (`content.ai_repair`) · **Змінити рівень/тему** → зміна лише метаданих · **Добре** → звичайна людська рецензія.

AI ніколи не буває м'якшим за власні критерії: якщо він поставив «ні» на «Без вигадок», а вердикт «Добре», вердикт автоматично піднімається до «Відхилити» (видно в Studio).

## Ранбук власника — по порядку

1. **Розмітити еталон (~200 питань).** Studio → Черга → Еталон. Кожне питання — 8 критеріїв «Так/Ні/?», вердикт підставляється сам. Ctrl+Enter — зберегти й далі. Мітки — мірило для AI, тож оцінюйте так, як хочете, щоб оцінював він.
2. **Застосувати міграцію `0014_question_assessments` на prod Supabase** — *потрібне ваше підтвердження* (нова таблиця, нічого не змінює в наявних). Без неї мітки й вердикти нікуди зберегти.
3. **AI переглядає еталон:**
   ```bash
   npm run ai -- ai-review --golden
   ```
   (сухий прогін: показує промпт і оцінку вартості), потім те саме з `--apply`. Потрібні `DATABASE_URL`, `CONTENT_AI_PROVIDER=gemini`, `GEMINI_API_KEY`.
4. **Калібрування:**
   ```bash
   npm run ai -- ai-calibrate
   ```
   або панель «Калібрування AI-рецензента» під Еталоном. Ворота довіри (узгодити з власником, `CALIBRATION_THRESHOLDS`): ≥ 100 пар, AI ловить ≥ 90% ваших «Відхилити», збіг вердиктів ≥ 75%. Якщо ні — дивимось розбіжності, правимо промпт (`AI_REVIEW_PROMPT_VERSION`) або рубрику (`ASSESSMENT_RUBRIC_VERSION`), повторюємо 3–4.
5. **Повний прогін по банку (~88 тис. питань)** — *потрібне ваше схвалення витрат Gemini*:
   ```bash
   npm run ai -- ai-review --all --signals-first --max-usd 20 --apply
   ```
   Команда відмовиться працювати, поки калібрування не пройде ворота. Прогін можна переривати й продовжувати — уже переглянуті питання пропускаються. Бюджет — жорстка зупинка; щоб продовжити, повторіть із більшим `--max-usd`.
6. **Черга рецензії.** Studio → Черга → AI-рецензія: спершу найризикованіші й ті, на які скаржились гравці. «Прийняти» (що саме зміниться — написано над кнопкою), «Змінити…» (свій рівень/тема/пояснення/прибрати з гри) або «Залишити як є». Можна масово.
7. **Застосувати рішення до банку:**
   ```bash
   npm run ai -- apply-review-decisions
   ```
   (сухий), потім `--apply`. Змінює `data/question-exclusions.json` і `data/question-overrides.json` — їх треба закомітити й задеплоїти, щоб зміни дійшли до гравців. Рішення по питанню, яке змінилось після рецензії, пропускаються (переглянути заново).
8. **Хвиля 1:**
   ```bash
   npm run ai -- migrate-wave --wave 1
   ```
   Тепер хвиля імпортує лише питання з актуальним AI-вердиктом і пропускає відхилені AI. Непереглянуті питання блокують `--apply` (обхід — `--allow-unreviewed`, лише з вашого дозволу). Правило «хвиля 1 на паузі» знімається, щойно L2 пройшов по питаннях хвилі.

## Уроки

Уроки тепер теж «fail closed»: ревізію уроку без запису перевірки (`lesson-checks@1`) не можна опублікувати. Після змін у перевірках уроків:

```bash
npm run ai -- validate-revisions --lessons --apply
```

## Спробувати локально без бази

```bash
npm run studio:sandbox -- --seed-ai --seed-golden 120
```

Пам'ять замість бази, евристичні «AI»-вердикти й фейкові мітки — щоб подивитись Еталон, Калібрування й AI-рецензію. Вебзастосунок окремо: `npm run dev` з `VITE_API_BASE_URL=http://localhost:3001`.
