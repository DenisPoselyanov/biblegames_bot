## 0. Що тобі реально потрібно знати

| Твої знання | Як використовуються тут |
|-------------|------------------------|
| **HTML** | Розмітка в файлах `.tsx` виглядає майже як HTML |
| **CSS** | Файли `.css` — звичайні стилі, можна правити як завжди |
| **JS (мінімум)** | Змінні, масиви, функції, `if`, цикл `for` — розділ 2 |
| **Не обов’язково зараз** | Класи, async/await, складний DOM, jQuery |

### Що НЕ треба вміти на старті

- Писати складний JavaScript з нуля
- Розуміти все в `node_modules/`
- Знати TypeScript на 100% (достатньо читати підказки в редакторі)

### Що треба вміти робити

- Відкрити файл у редакторі
- Знайти текст і змінити його (як у HTML)
- Змінити число в одному місці (наприклад, кількість питань)
- Скопіювати блок і вставити змінений (наприклад, нове питання)
- Запустити `npm run dev` у терміналі

## 1. HTML/CSS сайт vs цей проєкт

### Звичайний сайт (те, що ти знаєш)

```
index.html     →  розмітка
style.css      →  стилі
script.js      →  логіка (кліки, рахунок, збереження)
```

Ти сам:
1. Знаходиш елемент: `document.getElementById('score')`
2. Міняєш текст: `element.textContent = '100'`
3. Ховаєш/показуєш блоки для «сторінок»
4. Зберігаєш у `localStorage`

### Цей проєкт

```
index.html          →  одна порожня сторінка з <div id="root">
src/pages/*.tsx     →  «сторінки» (як HTML, але в окремих файлах)
src/*.module.css    →  стилі (як CSS)
src/data/*.ts       →  дані: теми, питання (як JSON у коді)
```

| Звично | Тут |
|--------|-----|
| `index.html` | Багато файлів у `src/pages/` |
| `script.js` | Логіка всередині `.tsx` + файли `data/`, `lib/` |
| `style.css` | `index.css` + `Home.module.css`, `Quiz.module.css`… |
| Відкрив `about.html` | URL `/about` → React показує потрібний файл |

**Vite** — програма, яка:
- запускає сайт локально (`npm run dev`);
- після збереження файлу **сама оновлює** сторінку в браузері;
- збирає все в папку `dist/` для Telegram.

**React** — бібліотека: ти **не шукаєш елементи в DOM**. Ти змінюєш **дані** (рахунок, номер питання), а React **сам перемальовує** HTML.

## 2. JavaScript — лише те, що зустрінеш тут

Читай цей розділ повільно. Цього достатньо для 90% правок у проєкті.

### 2.1 Змінна — «коробка з значенням»

```javascript
let score = 0;           // число
let name = 'Іван';       // текст (в лапках)
const MAX = 7;           // константа — не змінюємо
```

**У проєкті:** `QUESTIONS_PER_LEVEL = 7` у файлі `types/index.ts` — це така «коробка».

---

### 2.2 Масив — список

```javascript
const fruits = ['яблуко', 'груша', 'слива'];
fruits[0];   // 'яблуко' — перший (рахунок з 0!)
fruits[1];   // 'груша'
```

**У проєкті:** список тем `THEMES`, список варіантів відповіді `['Йордан', 'Ніл', 'Євфрат', 'Тигр']`.

---

### 2.3 Об’єкт — запис з полями

```javascript
const theme = {
  id: 'geography',
  title: 'Географія',
  icon: '🗺️',
};
theme.title;   // 'Географія'
theme.id;      // 'geography'
```

**У проєкті:** кожна тема і кожне питання — об’єкт.

---

### 2.4 Функція — дія, яку можна викликати

```javascript
function подвоїти(x) {
  return x * 2;
}
подвоїти(5);   // 10
```

**У проєкті:** `getQuestionsForLevel(...)` — функція, яка повертає 7 випадкових питань.

---

### 2.5 `import` і `export` — підключити інший файл

**Аналог у HTML:** `<script src="storage.js"></script>`, тільки в сучасних проєктах так:

```javascript
// у файлі storage.ts — «віддаємо назовні»
export function saveProfile(data) { ... }

// у іншому файлі — «беремо»
import { saveProfile } from './lib/storage';
```

**Правило:** рядки `import ...` завжди **на початку файлу**. Не треба їх боятися — це просто «підключи інший файл».

---

### 2.6 Стрілка `=>` — короткий запис функції

Це **те саме**, що `function`, тільки коротше:

```javascript
// Довго:
function add(a, b) { return a + b; }

// Коротко:
const add = (a, b) => a + b;
```

У React часто пишуть:
```javascript
onClick={() => handleSelect(0)}
```
Це означає: «при кліку виконай `handleSelect(0)`».

---

### 2.7 `?.` — «якщо є, тоді візьми»

```javascript
user?.first_name
```
Якщо `user` немає — не буде помилки, буде `undefined`.  
**У проєкті:** ім’я з Telegram може бути порожнім.

---

### 2.8 Файли `.ts` і `.tsx` — що це

| Розширення | Що всередині |
|------------|--------------|
| `.ts` | JavaScript + підказки типів (допомагає редактору) |
| `.tsx` | JavaScript + **HTML всередині** (JSX) |
| `.css` | Звичайний CSS |

**TypeScript (`.ts`)** — це JavaScript з «перевіркою помилок». Якщо редактор підкреслює червоним — щось не так із типом. Для правок тексту і даних часто можна ігнорувати складні типи.

---

### 2.9 JSX — HTML у JavaScript

```tsx
const name = 'Марія';
return (
  <p>Мир тобі, {name}!</p>
);
```

- Теги `<p>`, `<div>` — як у HTML.
- `{name}` — вставити значення змінної (як шаблон).
- Замість `class` пишуть `className` (бо `class` зайняте в JS).

**Тобі достатньо:** правити текст у тегах і дивитися на `{змінні}`.

## 5. Як відкривається сторінка

```
1. Браузер відкриває index.html
2. main.tsx каже: «намалюй <App /> у #root»
3. App.tsx дивиться на URL:
      /              → Home.tsx
      /themes        → Themes.tsx
      /themes/geography → ThemeDetail.tsx
      /quiz/geography/easy → Quiz.tsx
4. React показує потрібний файл з pages/
```

**Порівняння з HTML:** раніше ти б робив `quiz.html` або ховав `<div id="quiz">`. Тут адреса в браузері (`/quiz/...`) сама вибирає файл.

## 6. React простими словами

### 6.1 Компонент = шаблон сторінки

Файл `Home.tsx` — це **функція**, яка повертає HTML-подібний код.

```tsx
export function Home() {
  return (
    <section>
      <h1>Біблійна гра</h1>
    </section>
  );
}
```

**Ти можеш:** міняти текст у `<h1>`, додавати `<p>`, як у звичайному HTML.

---

### 6.2 Стан (state) — число/текст, який сам оновлює екран

**Раніше (JS):**
```javascript
let count = 0;
count++;
document.getElementById('count').textContent = count;
```

**Тут (React):**
```tsx
const [count, setCount] = useState(0);

// при кліку:
setCount(count + 1);   // React сам оновить текст на екрані
```

**Запам’ятай:** не шукай `getElementById` у `Quiz.tsx`. Шукай `useState` і `set...`.

---

### 6.3 Список тем — цикл `.map()` (замість копіювання HTML)

**Раніше:** 15 разів скопіював блок `<div class="card">`.

**Тут у `Themes.tsx`:**
```tsx
{THEMES.map((theme) => (
  <ThemeCard key={theme.id} theme={theme} />
))}
```

Це означає: «для кожної теми з масиву покажи картку».  
**Тобі достатньо:** додати об’єкт у `themes.ts` — картка з’явиться сама.

---

### 6.4 Context — «загальний зошит» для очок

Профіль гравця (очки, пройдені рівні) лежить у `PlayerContext.tsx`.

На будь-якій сторінці:
```tsx
const { profile } = usePlayer();
// profile.totalPoints — скільки очок
```

**Аналог:** один глобальний об’єкт `window.player`, тільки організовано.

## 7. Файли проєкту — що де лежить

### `types/index.ts` — налаштування гри (часто лише це треба)

```ts
export const QUESTIONS_PER_LEVEL = 7;   // скільки питань за один прохід

export const DIFFICULTY_POINTS = {
  beginner: 5,
  easy: 15,
  medium: 30,
  hard: 60,
  expert: 100,
};
```

Змінив число → зберег → перезавантаж сторінку в браузері.

---

### `data/themes.ts` — список тематик

Кожна тема — об’єкт у масиві. Додав об’єкт → тема з’явиться в грі.

---

### `data/questions.ts` + `questions-extra.ts` + `data/question-db/` — питання

- **questions.ts** — основні питання вручну
- **questions-extra.ts** — додаткові вручну
- **data/question-db/*.json** — тисячі питань від локальної AI (Ollama), див. `scripts/AI_SETUP.md`

**Як вибираються 7 питань:**
1. Збираються всі питання **цієї теми** і **цієї складності** (TS + JSON)
2. Перемішуються (випадковий порядок)
3. Беруться перші **7**

Кожен новий прохід рівня — **інший порядок** і **інша комбінація** з пулу.

---

### `pages/Quiz.tsx` — вікторина

- Питання і кнопки відповідей — **внизу** екрана (зручно для пальця в Telegram)
- Після відповіді — кнопка «Далі»
- В кінці — нарахування очок

---

### `lib/storage.ts` — збереження

Звичайний `localStorage` — як ти міг би писати в `script.js`. React тут майже не потрібен.

---

### Багато питань через AI (Ollama)

```bash
npm run generate-ai -- --theme geography --count 50
npm run questions:stats
```

Детально: **`scripts/AI_SETUP.md`**

## 8. Як працює гра

### Кроки для гравця

1. Обрати **тему** (Географія, Царі…)
2. Обрати **складність** (5 рівнів: від Початкового до Експерта)
3. Відповісти на **7 питань** (порядок випадковий)
4. Отримати **очки** в профіль

### Формула очок

```
очки = (очки за рівень) × (правильні відповіді ÷ 7)
```

Приклад: рівень «Складний» = максимум **60** очок.  
7 з 7 правильних → 60 очок.  
5 з 7 правильних → 60 × (5/7) ≈ **43** очки.

### 5 рівнів складності

| Рівень | Назва | Макс. очок |
|--------|-------|------------|
| beginner | Початковий | 5 |
| easy | Легкий | 15 |
| medium | Середній | 30 |
| hard | Складний | 60 |
| expert | Експерт | 100 |

## 9. Практика: що відкрити і що написати

### 9.1 Змінити текст на головній

1. Відкрий `src/pages/Home.tsx`
2. Знайди потрібний рядок у лапках, наприклад: `<h1>Біблійна гра</h1>`
3. Зміни текст, збережи (Ctrl+S)
4. Подивись у браузер — має оновитись сам

Стилі: `src/pages/Home.module.css`

---

### 9.2 Додати нову тему (без складного JS)

**Крок 1.** `src/data/themes.ts` — скопіюй блок іншої теми і зміни:

```ts
{
  id: 'angels',              // латиницею, для URL
  title: 'Ангели',
  description: 'Гавриїл, Михаїл та інші',
  icon: '👼',
  color: '#6b8fd4',
},
```

**Крок 2.** Додай хоча б кілька питань з `themeId: 'angels'` у `questions.ts` (див. 9.3).

Тема з’явиться в списку **сама**.

---

### 9.3 Додати одне питання (найпростіший спосіб)

Відкрий `src/data/questions.ts`, знайди функцію `q(` і **скопіюй** один рядок, наприклад:

```ts
q('geography', 'easy', 11, 'Твоє питання?', ['Вірно', 'Ні', 'Ні', 'Ні'], 0, 'Ін. 3:16'),
```

| Параметр | Що означає |
|----------|------------|
| `'geography'` | id теми |
| `'easy'` | складність: `beginner`, `easy`, `medium`, `hard`, `expert` |
| `11` | номер (унікальний для цієї теми+складності) |
| `'Твоє питання?'` | текст |
| `['Вірно', 'Ні', ...]` | 4 варіанти |
| `0` | який варіант правильний: 0=перший, 1=другий… |
| `'Ін. 3:16'` | посилання (можна прибрати) |

Збережи файл.

---

### 9.4 Змінити кількість питань (наприклад, 10 замість 7)

**Один файл:** `src/types/index.ts`

```ts
export const QUESTIONS_PER_LEVEL = 10;
```

У `ThemeDetail` текст «7 запитань» оновиться автоматично.

---

### 9.5 Змінити очки за рівень

**Файл:** `src/types/index.ts` → блок `DIFFICULTY_POINTS`. Зміни число, збережи.

---

### 9.6 Змінити кольори (як завжди в CSS)

**Файл:** `src/index.css`

```css
:root {
  --bg: #1a1208;        /* фон */
  --gold: #c9a227;      /* золотий акцент */
  --text: #f5f0e6;      /* текст */
}
```

Це звичайний CSS — тут ти вже на «своїй» території.

---

### 9.7 Вікторина: питання внизу екрана

| Що | Файл |
|----|------|
| Розмітка (що зверху, що знизу) | `pages/Quiz.tsx` |
| Вигляд нижньої панелі | `pages/Quiz.module.css` → клас `.bottomPanel` |

---

### 9.8 Додати багато питань одразу

1. Встанови [Ollama](https://ollama.com) і запусти `ollama serve`
2. У терміналі:
   ```bash
   npm run generate-ai -- --theme geography --count 100
   ```

## 10. Порівняння зі звичайним HTML

| Задача | HTML + CSS + JS (ти знаєш) | Цей проєкт |
|--------|----------------------------|------------|
| Змінити заголовок | Відкрив html, змінив `<h1>` | Відкрив `Home.tsx`, змінив `<h1>` |
| Змінити колір | `style.css` | `index.css` або `*.module.css` |
| Нова сторінка | Новий `.html` + посилання | Новий файл у `pages/` + рядок у `App.tsx` |
| Список карток | 15 разів HTML | Один масив у `themes.ts` |
| Рахунок очок | `getElementById` + `textContent` | `useState` / `usePlayer()` |
| Зберегти прогрес | `localStorage` вручну | `lib/storage.ts` (те саме) |
| Випадкові питання | Сам писав shuffle | `getQuestionsForLevel()` |

### Що спочатку здається складним

- `import` / `export`
- `useState`, `useEffect`
- Файли `.tsx`
- Термінал і `npm`

### Що потім стає **простіше**, ніж один великий `script.js`

- Додати тему — один об’єкт у масиві
- Змінити 7 → 10 питань — одне число
- Стилі не ламають один одного (`*.module.css`)
- Не губишся, «де оновлюється рахунок»

## 12. Збірка для публікації

```
Ти правиш файли в src/
        ↓
npm run build
        ↓
Готова папка dist/  →  завантажуєш на хостинг
```

Браузер **не розуміє** `.tsx` напряму. Vite перетворює все в звичайний `.js`, як твій `script.js`, тільки зібраний і стиснутий.

## 13. Словник

| Слово | Простими словами |
|-------|------------------|
| **npm** | Програма, що ставить бібліотеки і запускає команди |

| **Route** | Адреса в браузері → який екран показати |
| **localStorage** | Пам’ять браузера (зберігає очки) |
| **import** | Підключити код з іншого файлу |
| **export** | «Віддати» функцію/змінну іншим файлам |
| **map** | Цикл: зробити HTML для кожного елемента масиву |
