# Прототип дизайну v2 (`/proto`)

Клікабельний прототип нового вигляду Bible Games. Живе поруч із чинним застосунком
і **не змінює жодного наявного екрана**.

## Як відкрити

```bash
npm run dev
```

далі `http://localhost:5173/proto` (порт залежить від конфігурації dev-сервера).

На екранах ≥ 900px прототип показується в рамці телефона — це режим перегляду,
цільовий форм-фактор залишається Telegram Mini App 390×844.

## Рішення, зафіксовані на старті

| Питання | Рішення |
|---|---|
| Розміщення | окремий маршрут `/proto` у цьому ж React-проєкті |
| Візуальний напрям | Hallow / Glorify / YouVersion — «духовний преміум» |
| Платформа | Telegram Mini App, тільки мобільний |
| Теми | темна (за замовчуванням) + світла, перемикач у профілі |
| Палітра | індиго/фіолет + тепле золото як акцент |
| Типографіка | Manrope (UI) + Literata (заголовки, Писання) |
| Гейміфікація | збалансована: стрік і прогрес видимі, монети/беджі — другим планом |
| Стек | Tailwind v4 + власні примітиви, framer-motion, lucide |
| Дані | моки + справжня локальна інтерактивність |
| Навігація | нижні таби ×5: Сьогодні · Навчання · Грати · Прогрес · Я |
| Motion | середній: пружні переходи, мікровзаємодії, `prefers-reduced-motion` |

## Ізоляція від чинного застосунку

- `App.tsx` віддає `ProtoApp` **до** всіх провайдерів, тому cosmetic-theme sync,
  react-vant, react-query і bootstrap профілю для `/proto` не виконуються.
- `proto.css` не імпортує Tailwind preflight, а всі базові правила загорнуті в
  `:where(.proto-root)`, тож нічого не протікає в legacy-стилі.
- Утиліти Tailwind свідомо **поза** cascade layer: глобальний `src/index.css` не
  має шарів, і будь-який шар програв би його селекторам за елементами.
- Сканування класів обмежене каталогом `src/proto` (`@source './'`).

## Структура

```
proto/
  proto.css         токени (--p-*), обидві теми, фон-аврора, рамка телефона
  ProtoApp.tsx      оболонка: аврора, таб-бар, маршрути
  lib/mock.ts       контент (плани, модулі, урок, питання, прогрес)
  lib/protoContext  типи + контекст стану
  lib/store.tsx     провайдер стану + дзеркало в localStorage
  lib/useProto.ts   хук + розрахунок рівня
  ui/kit.tsx        Card, Button, Pill, Meter, Ring, Segmented, Cover
  screens/          16 екранів
```

## Що вже працює по-справжньому

- урок читається блоками, checkpoint блокує «Далі» до правильної відповіді;
- практика: таймер, підрахунок, пояснення з посиланням на вірш, екран результату;
- «Мільйонер»: драбина на 15 щаблів, три підказки, гарантовані суми;
- «Виживання»: три життя, серія, рекорд;
- XP, монети, прогрес уроку й результат зберігаються між перезавантаженнями;
- перемикач темна/світла тема.

## Правила, які випливли з першого перегляду

- **Одна головна кнопка.** Індиго→фіолет; на кольоровій поверхні вона
  інвертується в білу (`variant="onColor"`). Золото — лише акцент.
- **Кольорові картки для головного об'єкта екрана** («Урок дня», «Гра тижня»,
  фінальні оверлеї): обкладинка розтягується під усю картку, текст білий.
- **Градієнти шкал** закінчуються золотом лише в темній темі (`--p-ramp-end`).
- **Фінальні екрани не скролять** — розміри рахуються від висоти вікна.

## Наступна ітерація

Онбординг, екран пошуку/каталогу, сторінка вірша дня, порожні стани й помилки.
Далі — заміна `lib/mock.ts` на типи з `contracts/` і реальні виклики
`/api/v1/learning/*`.
